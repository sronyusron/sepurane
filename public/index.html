Cara Kerja

Dashboard ini digunakan untuk mengatur konfigurasi bot secara online melalui browser.


Semua data disimpan di localStorage browser Anda dan bisa di-export sebagai file untuk dijalankan di komputer/VPS.


Alur kerja:

  1. Atur semua konfigurasi di dashboard ini
  2. Klik Export untuk download file config
  3. Letakkan file config di folder bot
  4. Jalankan node loketbot.js di PC/VPS

Bantuan & FAQ

Apa itu Sepurane?

Sepurane adalah bot otomatis untuk membeli tiket di Loket.com. Dashboard ini membantu Anda mengatur konfigurasi bot secara online.

Apakah data saya aman?

Semua data disimpan di localStorage browser Anda. Tidak ada data yang dikirim ke server manapun. Data hanya ada di perangkat Anda.

Bagaimana cara menjalankan bot?

Setelah mengatur konfigurasi, export file-nya lalu jalankan di komputer/VPS dengan Node.js menggunakan perintah node loketbot.js.

Kenapa bot tidak bisa jalan di Vercel?

Vercel adalah hosting untuk website statis/serverless. Bot membutuhkan proses yang berjalan terus-menerus (long-running), sehingga harus dijalankan di PC atau VPS.

Apa yang dibutuhkan untuk menjalankan bot?

Anda memerlukan: Node.js v16+, npm, dan koneksi internet. Install dependencies dengan npm install lalu jalankan bot.
